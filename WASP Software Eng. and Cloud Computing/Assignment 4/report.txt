In this assignment we have setup a backup process for a filesystem. The process is rather simple. Every 5 minutes a backup job is launched (in a separate VM, we could launch this as something more lightweight too that wouldn't require a permantent VM like a serverless job) to aggregate and compress the files, and copy them to a backup container in a cloud object store. The exercise shows how we can add redundancy to prevent losing data in case a single machine/volume fails. We could also make it more complex, for example, by adding rotation to the backups such that we do not keep adding up to the storage required for the backups.
